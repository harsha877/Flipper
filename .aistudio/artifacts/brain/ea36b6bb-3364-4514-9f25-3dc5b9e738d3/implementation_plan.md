# Retunda — Clean 3-Step AI Upload Wizard & Safe GitHub Setup Plan

## 1. Streamlined Editor Mode: 3-Step Guided Page Wizard
All manual product editing forms, starter templates (*"Or Start From a Template / Existing Page"*), and extra tabs will be removed from Editor Mode.

When you unlock Editor Mode (`/?admin=retunda` or `Shift + Alt + A`), you will see a clean, focused **3-Step Guided Wizard**:

### Step 1: Download `instruction.md` for AI
* A single card with **Download `instruction.md`** and **Copy Instructions** buttons.
* Give this file to ChatGPT, Claude, or Gemini along with your topic or Amazon links so the AI generates a complete, properly styled `<slug>.txt` file.

### Step 2: Upload Your `.txt` Page File
* A drag-and-drop / file-picker upload box where you select the `.txt` file generated by your AI.
* Automatically validates the uploaded `.txt` file and shows a clean summary preview (Page Title, Category, Number of Amazon Products parsed, and formatted `?tag=retunda-20` links).

### Step 3: Select Directory Path & Publish to GitHub
* **Choose Target Directory**: Select a folder preset (`src/content/pages`, `src/content/pages/living-room`, `src/content/pages/kitchen`, `src/content/pages/workspace`, `src/content/pages/bath-spa`) or type any custom folder path.
* **Publish to GitHub**: Commits the uploaded `.txt` file directly to that folder in your GitHub repository via the GitHub API and gives you the ready-to-copy **Pinterest Destination Link** (`https://retunda.dpdns.org/?page=<path>`).

## 2. What GitHub Details Are Needed & Is It Safe to Store Them in the Repo?

| Setting | Example | Safe in Public GitHub Repo? | Why |
| :--- | :--- | :--- | :--- |
| **`GITHUB_OWNER`** | `hharsha107` | **Yes (100% Safe)** | Just your public GitHub username so browsers know where to read `.txt` pages. |
| **`GITHUB_REPO`** | `retunda` | **Yes (100% Safe)** | Just your public repository name. |
| **`GITHUB_BRANCH`** | `main` | **Yes (100% Safe)** | The branch name to read/write `.txt` files on. |
| **`GITHUB_FOLDER`** | `src/content/pages` | **Yes (100% Safe)** | The root folder where your page `.txt` files live. |
| **GitHub Personal Access Token (PAT)** | `github_pat_...` | **NEVER in plain text!** | GitHub automatically revokes any raw token committed in plain text. Instead, either **encrypt it inside `ADMIN_VAULT` (AES-256-GCM)** or **keep it only in your browser** during Step 3. |

### How to Create a Safe, Restricted GitHub Token (Takes 60 Seconds):
1. Go to **GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. Under **Repository access**, select **Only select repositories** and pick ONLY your `retunda` repository.
3. Under **Permissions → Repository permissions**, set **Contents** to **Read and write** (leave everything else as *No access*).
4. Copy the generated `github_pat_...` token and either:
   * Paste it once in Step 3 (saved only in your own browser's local storage, never in the GitHub repo), **OR**
   * Encrypt it with your password inside `ADMIN_VAULT` (AES-256-GCM ciphertext).
